# Bin Rabie Holding CRM

A professional bilingual (Arabic/English) CRM dashboard for **Bin Rabie Holding Group** (مجموعة بن ربعي القابضة), built with Next.js 16, React 19, TypeScript, and Tailwind CSS.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the CRM dashboard.
